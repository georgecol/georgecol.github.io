#### definition
```
$PATH
```
Environment variable that contains a colon-separated list of directories:
e.g
```bash
/usr/local/bin:/usr/bin:/bin
```
Searches directories in order

Update the variable
```
export PATH="stufftoadd":$PATH
```
to add stuff to front of path
