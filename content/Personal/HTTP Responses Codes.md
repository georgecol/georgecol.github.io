That I know of -
200-299 - indicates success, that the recipient has received the message.

200 - OK
204 - No content
300-399 - redirection - generally url redirection to complete the request
400-499 - client error - status code for different situations when your request is bad
e.g 
400 - bad request , server can't process
401 - unauthorised
402 - payment required
403 - forbidden - valid request but not the right permissions
404 - error page not found
